# FINALE — Version 8 Baseline

사진 동아리 전시회의 마지막 공간에서 관람객의 문장을 영화 엔딩 크레딧처럼
흘려보내는 참여형 미디어아트 웹 프로젝트입니다.

이 `main`은 최종 완성본이 아니라, 이후 입력/출력 분리와 연출 실험을 시작하기 위한
**Version 8 기준점**입니다. 전시장용으로 유지할 안정 버전과 새로운 실험을 비교할 때
기준으로 사용합니다.

## Version 8의 의도

- 영화 엔딩 크레딧처럼 절제된 움직임과 긴 여운을 만든다.
- `FINALE; TUNE A` 제목을 크레딧 흐름 안에 배치한다.
- 관람객의 문장이 기존 문장들과 함께 반복되는 구조를 만든다.
- 입력 기능이 작품 감상을 방해하지 않도록 숨겨진 컨트롤로 둔다.
- 검은 화면, 얇은 본문, 반복되는 세로 흐름으로 전시 마지막 장면을 만든다.

## 현재 구현

- React + TypeScript + Vite
- `requestAnimationFrame` 기반 크레딧 롤링
- `translate3d` 기반 무한 반복 이동
- `ResizeObserver` 기반 화면 크기 대응
- 입력 문장 저장: 브라우저별 `localStorage`
- 입력 후 최신 문장 중앙 강조
- `prefers-reduced-motion` 대응
- 배경음악 파일이 있을 때만 오디오 컨트롤 활성화

현재는 하나의 브라우저 안에서 동작합니다. 입력 노트북과 출력 iMac 사이의 실시간
연동은 아직 구현하지 않았으며, 다음 작업 브랜치에서 별도로 진행합니다.

## 체크포인트 기록

### Checkpoint 1 — 기본 타이포그래피

- 한글 `SUIT`, 영문 `Helvetica` 계열 적용
- 행간과 문장 간격을 엔딩 크레딧에 맞게 축소

### Checkpoint 2 — 크레딧 밀도 조정

- 글자 크기와 라벨 크기 축소
- 화면 폭과 행간을 조정해 더 촘촘한 영화 엔딩 크레딧 구성

### Checkpoint 3 — 인터랙티브 롤링 구조

- 타이틀, 질문, 문장 입력, 샘플 방명록 구성
- 아래에서 위로 흐르는 무한 롤링 구현
- `localStorage` 저장과 모바일 입력 화면 추가

### Checkpoint 4 — 화면 정리

- 배경을 검정으로 통일
- 불필요한 전시 정보와 안내 문구 제거
- 타이틀 표현을 `F; tune A`에서 `Finale; tune A`로 조정

### Checkpoint 5 — 타이틀 롤링 합류

- 타이틀을 고정 위치에서 제거
- 각 크레딧 그룹 안에 타이틀을 삽입
- 반복될 때 타이틀도 함께 흐르도록 구성

### Checkpoint 6 — Version 8 기준점

- 타이틀을 `FINALE; TUNE A`로 확정
- Futura 계열 우선의 Black 스타일 제목
- 제목은 강하게, 본문은 절제된 위계로 구성

### Checkpoint 7 — Version 10 후보와의 비교 대상

- 제목 크기 확대
- 제목 외 영문 텍스트 두께를 더 얇게 조정
- Version 8은 절제와 장시간 감상을 우선하는 기준점으로 선정

## 실행

```bash
npm install
npm run dev
```

빌드 및 전시장 전 테스트:

```bash
npm run build
npm run preview
```

빔프로젝터에 연결한 Chrome에서 전체 화면으로 실행합니다.

## 기록 초기화

테스트 중 저장된 문장을 지우려면 브라우저 콘솔에서 실행합니다.

```js
window.__finaleDevReset()
```
